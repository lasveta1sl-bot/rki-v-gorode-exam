# В городе — от учебника к экзамену

Публичный макет нового отдельного сайта. Тема: урок 9 «В городе» учебника «Базовый аудиовизуальный курс русского языка», часть 2 (俄语视听说基础教程2).

## Содержание

- Главная связывает конкретный учебник, повторение темы и задание 1 экзамена.
- Блок подготовки: активный словарь 9.1, исходные предложения, текстовый разбор формата, просмотр всех 46 позиций банка.
- Вход по имени, сохранение имени и отметок повторения только в браузере.
- Источники каждой позиции и ключ сохраняются. Содержание банка перенесено без изменений из Word-банка от 18 ноября 2026 года.

## Статус

Это макет для проверки, не готовый аудиотренажёр. Аудиозаписи не подключены. Просмотр исходного текста доступен явно; ответы аудирования отключены, оценка и готовность к экзамену не рассчитываются. Синтеза речи нет. Полный PDF учебника и экзаменационные бланки не публикуются.

39 позиций содержат 1–2 изменения, 7 совпадают (15,2%). Все исходные печатные предложения 9.3, 9.5 и восемь городских сегментов экзаменационного задания 1 покрыты с объединением дословных дублей. Дополнительно включены четыре фрагмента из ранее согласованного сопоставления.

## Запуск

Статический сайт без сборки. Для локального просмотра: `python3 -m http.server 8765` из этой папки. Для GitHub Pages: ветка `main`, каталог `/ (root)`.

## Дальнейшая работа

После проверки содержания — сверка и подключение записей, аудиодемонстрация, реальная проверка ответов, выбор разнообразного прохода из банка и проверка повторов. В существующие сайты этот макет изменений не вносит.
