# В городе — от учебника к практике

Тренировка по уроку 9 «В городе» учебника «Базовый аудиовизуальный курс русского языка», часть 2 (俄语视听说基础教程2).

Это похожие предложения для тренировки, а не экзаменационные задания.

## Содержание

- Активный словарь 9.1 и предложения по теме.
- Связь с материалом 9.3, 9.5 и другими фрагментами урока.
- Разбор сравнения услышанного с написанным.
- 46 тренировочных примеров: 39 с отличиями и 7 совпадающих (15,2%).
- Сохранение имени и отметок повторения только в браузере.

## Статус

Подключены 36 слов из записи к упражнению 9.1 и 46 предложений в записи преподавателя, включая исправленные фразы 18 и 21. Все аудиофрагменты встроены в HTML страницы подготовки. Главная страница не загружает аудио. Доступны прослушивание, пауза, продолжение, остановка и замедление той же записи. Текст и разбор открываются после ответа. Полные учебные документы не публикуются.

## Запуск

Статический сайт без сборки. Локально: `python3 -m http.server 8765`. GitHub Pages: `main`, `/ (root)`.
